# Galamat — сайт холдинга

Сайт технологического и медиа-холдинга Galamat (Galamat Tech + Galamat Media, Алматы).

- **Живой сайт:** https://rairayev.github.io/galamat/ (GitHub Pages, ветка `main`, корень репозитория)
- **Дизайн в Figma:** файл [NEW-GALAMAT](https://www.figma.com/design/FCGPn9zKV001lbfNKnqewS/NEW-GALAMAT)
  - страница «Сайт — актуальная версия (как на сайте)» — главная и «Команда» в том виде, как сейчас на сайте
  - страница «Page 4» — исходный макет заказчика и кадры анимаций («стейт 1/2/3», «СТЕЙТ 1/2 КОНЕЦ»)
- **Бенчмарки:** документ «Galamat — бенчмарки» в Claude

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Главная |
| `team.html` | Страница «Команда» |
| `assets/css/style.css` | Все стили. Блоки нового дизайна — в конце файла (раздел `v3 — redesign from Figma`) |
| `assets/js/main.js` | Меню, 3D-кольцо карточек, проявление текста из размытия, кадры блока «Сделано в Казахстане», анимация блока контактов, плавная прокрутка |

Сайт статический: без сборки, без фреймворков. Шрифт — Inter (Google Fonts). Плавная прокрутка — Lenis 1.1.20 с jsDelivr.

## Правила стиля

- Шрифт Inter; основной цвет `#0077FF`; тёмный `#171717`; серый фон `#F5F5F7`.
- Логотип — только синий, белый или монохром.
- Минимализм, крупная типографика с отрицательным межбуквенным интервалом.

## Как устроены эффекты

- **Hero, кольцо карточек:** CSS 3D (`.ring-stage`, `.ring-card`), размеры считаются от ширины экрана в `main.js`. Крутится само, тянется мышью/пальцем, прокрутка его подталкивает.
- **Слоган «Делаем добро узнаваемым»:** 9 слоёв текста с градиентом через `background-clip: text` (`.echo-l`), чистый CSS, без SVG — так работает в Safari.
- **Проявление из размытия** (`.blur-reveal`): текст разбивается на слова, размытие снимается по мере прокрутки.
- **«Сделано в Казахстане»** (`.kz-v3`): блок высотой 320vh с липкой сценой, три кадра по прогрессу прокрутки. На телефоне и при отключённых анимациях — статичная раскладка.
- **«Давайте создадим что-то вместе»** (`.cta-v3`): заголовок съезжает из центра влево, кнопки и контакты проявляются.
- После правок CSS/JS увеличивать версию в ссылках (`style.css?v=N`, `main.js?v=N`) в обоих HTML, иначе браузеры покажут старую версию из кэша.

## Публикация

Git на компьютере заказчика не установлен. Файлы загружаются одним коммитом через GitHub API с помощью GitHub CLI (аккаунт `RaiRayev`): для каждого файла создаётся blob, затем дерево, коммит и обновление `refs/heads/main`. GitHub Pages пересобирает сайт за 1–2 минуты.
