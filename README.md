# Galamat — сайт

Статический сайт холдинга Galamat (Galamat Tech + Galamat Media).

- `index.html` — главная
- `team.html` — страница «Команда»
- `assets/css/style.css`, `assets/js/main.js`, `assets/img/` — стили, скрипты, фото

## Публикация на GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
Сайт появится по адресу `https://<username>.github.io/<repo>/`.

## Что заменить
- `team.html`: имена, должности и фото команды (сейчас заглушки)
- Блок «Партнёры»: текстовые названия → SVG-логотипы
